# 在？点一炮？前端

这是一个基于Web的积分器应用，支持多人实时计分，**专为移动端优化**。

## 功能特性

- 🏠 自动创建房间或加入现有房间
- 👤 用户姓名设置和本地缓存
- 📱 二维码分享房间链接
- 📊 实时积分记录和日志
- ✅ 批量确认分数变更
- 🔄 自动数据同步

## 🚀 移动端优化特性

- 📱 **响应式设计**: 完美适配各种屏幕尺寸
- 👆 **触摸优化**: 更大的触摸目标，防止误触
- 🔄 **下拉刷新**: 类似原生应用的下拉刷新体验
- 📳 **震动反馈**: 支持设备震动反馈（如果可用）
- ⚡ **长按功能**: 长按加分按钮快速加5分
- 🌙 **深色模式**: 自动适配系统深色模式
- 📱 **PWA支持**: 可添加到主屏幕，类似原生应用
- 🎯 **防误触**: 防止双击缩放，优化触摸事件
- 💫 **流畅动画**: 60fps流畅的过渡动画
- 🎨 **现代UI**: 渐变色彩和圆角设计

## 使用说明

1. **创建房间**: 首次访问时会自动创建房间并生成房间ID
2. **设置姓名**: 输入您的姓名，系统会保存到本地缓存
3. **分享房间**: 扫描二维码或复制链接邀请他人加入
4. **计分操作**: 
   - 点击成员旁边的"+"按钮为其加分
   - **移动端**: 长按"+"按钮可快速加5分
5. **确认提交**: 有分数变更时会显示确认按钮，点击后统一提交
6. **重新创建**: 点击右上角"重新创建房间"按钮可重新开始
7. **移动端特有功能**:
   - 下拉页面顶部可刷新数据
   - 支持震动反馈（如果设备支持）
   - 自动适配深色模式

## 技术栈

- **构建工具**: Webpack 5
- **样式**: CSS3 + 响应式设计
- **二维码**: qrcode.js
- **模块化**: ES6 Modules

## API接口

应用会尝试调用以下API接口（如果后端不可用会使用模拟数据）：

- `POST /api/rooms` - 创建房间
- `POST /api/users` - 创建用户
- `GET /api/rooms/:roomId` - 获取房间数据
- `POST /api/rooms/:roomId/scores` - 提交分数变更

## 移动端优化详情

### 响应式设计
- 使用CSS Grid和Flexbox布局
- 针对不同屏幕尺寸的媒体查询
- 触摸友好的按钮尺寸（最小44px）

### 触摸优化
- 防止双击缩放
- 优化触摸事件处理
- 添加触摸反馈动画

### 性能优化
- 使用CSS transform进行动画
- 优化滚动性能
- 减少重绘和回流

### 用户体验
- 流畅的过渡动画
- 直观的视觉反馈
- 符合移动端操作习惯
