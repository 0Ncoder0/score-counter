# 积分器功能需求文档

## 概述
这是一个基于Web的积分器应用，支持多人实时计分。

## 核心功能

### 1. 房间管理
- 自动创建房间或加入现有房间
- 房间ID显示在页面顶部
- 支持重新创建房间功能

### 2. 用户管理
- 首次访问时要求输入姓名
- 用户信息保存到本地缓存
- 支持二维码分享房间链接

### 3. 积分系统
- 显示所有成员的积分
- 点击"+"按钮为成员加分
- 支持批量确认分数变更
- 实时显示待确认的分数变更

### 4. 日志记录
- 记录所有积分操作
- 显示操作人和操作内容
- 自动滚动到最新记录

### 5. 实时更新
- 每300毫秒查询一次数据更新
- 自动同步房间状态
- 支持多用户同时操作

## 技术实现

### 前端技术栈
- HTML5 + CSS3
- JavaScript ES6+
- Webpack 5 构建工具
- qrcode.js 二维码生成

### API接口
- POST /rooms - 创建房间
- POST /rooms/:roomId/members - 添加成员
- GET /rooms/:roomId - 获取房间数据
- POST /rooms/:roomId/transfer - 分数转移

### 数据同步
- 轮询机制：每300ms查询一次
- 本地缓存用户信息
- 实时更新界面状态

## 界面布局

### 头部区域
- 房间ID显示
- 重新创建房间按钮

### 主要内容区域
- 左侧：积分记录日志
- 右侧：成员列表和积分操作

### 模态框
- 姓名输入
- 二维码显示
- 房间链接分享

## 响应式设计
- 支持桌面和移动设备
- 自适应布局
- 触摸友好的操作界面
